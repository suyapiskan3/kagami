# Кагами — сайт салона красоты

Одностраничный сайт салона красоты «Кагами» (г. Южно-Сахалинск, ул. Чехова, 41, 1 этаж).

Весь код (HTML, Tailwind CSS через CDN, JavaScript) находится в одном файле `index.html`.

## Возможности

- Адаптивная вёрстка в стиле премиального минимализма: крем, графит, бронза.
- Каталог услуг с ценами и плашка «Скидка 5% при оплате наличными».
- Онлайн-запись в 4 шага: услуги (сумма считается на лету), мастер, время, контакты.
- Демо-CRM в подвале («Панель администратора»): записи хранятся в `localStorage`, есть очистка базы.

## Запуск

Откройте `index.html` в браузере. Нужен интернет: Tailwind, иконки и шрифты загружаются с CDN.

## Перед запуском в работу

- Замените имена и описания мастеров (сейчас это примеры).
- Добавьте ссылки на соцсети и настоящие фотографии.
- Записи хранятся только в браузере посетителя; для реальной работы нужен сервер.
