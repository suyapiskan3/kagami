# Кагами — сайт салона красоты

Одностраничный лендинг салона красоты «Кагами» (г. Южно-Сахалинск, ул. Чехова, 41, 1 этаж).

Сайт: https://suyapiskan3.github.io/kagami/

Весь код (HTML, Tailwind CSS через CDN, JavaScript) — в одном файле `index.html`.

## Что на сайте

- Логотип салона, палитра в тёплых красных тонах.
- Каталог услуг по разделам: волосы, педикюр, уход за лицом, косметология, LPG-массаж, лазер, пирсинг (цены «от» по прайсу салона в 2ГИС).
- Мастера, контакты, ссылка на карточку в 2ГИС, плашка «Скидка 5% при оплате наличными».

## Онлайн-запись

Запись ведётся в DIKIDI. Все кнопки «Записаться», «Выбрать время» и «Записаться к мастеру» открывают в новой вкладке
https://dikidi.ru/2031683

Ссылка задаётся в двух местах `index.html`: в константе `BOOKING_URL` (кнопки в каталоге и у мастеров) и в атрибутах `href` статичных кнопок. Чтобы поменять её, замените `https://dikidi.ru/2031683` поиском по файлу.

## Перед запуском в работу

- Замените имена и описания мастеров (сейчас это примеры).
- Добавьте ссылки на соцсети и настоящие фотографии.
