# Кагами — сайт салона красоты

Сайт салона красоты «Кагами» (г. Южно-Сахалинск, ул. Чехова, 41, 1 этаж).

| Файл | Что это |
|---|---|
| `index.html` | Сайт: каталог услуг по разделам, онлайн-запись в 4 шага |
| `admin.html` | Кабинет администратора: все записи, статусы, поиск, выгрузка в CSV |
| `config.js` | Настройка: адрес Google Таблицы для записей |
| `google-apps-script.gs` | Код для Google Таблицы (копируется в Apps Script) |

Сайт: https://suyapiskan3.github.io/kagami/
Кабинет администратора: https://suyapiskan3.github.io/kagami/admin.html

## Два режима работы

- **Демо-режим** (сейчас, `apiUrl` в `config.js` пустой). Записи хранятся только в браузере, где их сделали. В `admin.html` видны лишь записи с этого же устройства. Подходит для показа.
- **Рабочий режим** (после подключения Google Таблицы). Каждая запись с сайта попадает в Google Таблицу. Администратор открывает `admin.html` с любого телефона или компьютера, вводит пароль и видит все записи.

## Подключение Google Таблицы (около 10 минут)

1. Откройте https://sheets.new — создастся новая Google Таблица. Назовите её, например, «Кагами — записи».
2. В меню таблицы выберите **Расширения → Apps Script**.
3. Удалите всё в редакторе и вставьте содержимое файла `google-apps-script.gs` из этого репозитория.
4. В строке `const ADMIN_PASSWORD = 'ЗАМЕНИТЕ-НА-СВОЙ-ПАРОЛЬ';` впишите свой пароль (не короче 10 символов). Нажмите значок дискеты (**Сохранить**).
5. Нажмите **Начать развертывание → Новое развертывание**. Шестерёнка рядом с «Выберите тип» → **Веб-приложение**.
   - **Запуск от имени:** «Я».
   - **У кого есть доступ:** «Все».
   - Нажмите **Начать развертывание**, затем **Предоставить доступ** и выберите свой аккаунт Google. Если появится «Google не проверил это приложение», нажмите **Дополнительные настройки → Перейти на страницу проекта (небезопасно)** → **Разрешить**. Это ваш собственный скрипт.
6. Скопируйте **URL веб-приложения** (начинается с `https://script.google.com/macros/s/…/exec`).
7. Откройте в репозитории файл `config.js`, нажмите карандаш (**Edit**) и вставьте адрес между кавычками:
   ```js
   window.KAGAMI_CONFIG = {
     apiUrl: 'https://script.google.com/macros/s/ВАШ_АДРЕС/exec'
   };
   ```
   Нажмите **Commit changes**. Через 1–2 минуты сайт обновится.
8. Сделайте тестовую запись на сайте и откройте `admin.html`: после ввода пароля она появится в списке. Записи также видны в самой таблице на листе «Записи».

**Если поменяли код скрипта или пароль**, обновите развёртывание: **Начать развертывание → Управление развертываниями → карандаш → Версия: «Новая версия» → Развернуть**. Адрес при этом не меняется.

## Безопасность

- Пароль хранится только в Google Apps Script и не попадает на сайт. Без пароля записи прочитать нельзя.
- Адрес скрипта виден в коде сайта, поэтому кто угодно может отправить через него запись — так же, как через форму. Если начнётся спам, напишите — можно добавить защиту.
- Страница `admin.html` закрыта от поисковиков (`noindex`).
